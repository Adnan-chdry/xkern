SEABIOS - USB SUBSYSTEM REFERENCE NOTICE
===============================================================================

This project's USB implementation draws design inspiration from, and references
concepts found in, the SeaBIOS project's USB subsystem.

--------------------------------------------------------------------------------
ACKNOWLEDGMENT
--------------------------------------------------------------------------------

SeaBIOS is an open-source legacy BIOS implementation which can be used as a
coreboot payload [citation:4]. It implements standard BIOS calling interfaces
for x86 systems.

The USB subsystem in SeaBIOS was developed by:

  Kevin O'Connor (primary author)
  And many other SeaBIOS contributors

The SeaBIOS project website:
  http://www.coreboot.org/SeaBIOS

SeaBIOS source repository:
  https://git.seabios.org/seabios.git/

This project is inspired by SeaBIOS USB functionality including:

  - USB EHCI controller support
  - USB XHCI controller support
  - USB MSC (Mass Storage Class) device support
  - USB UAS (USB Attached SCSI) device support
  - USB hub support including USB3 hubs [citation:2]
